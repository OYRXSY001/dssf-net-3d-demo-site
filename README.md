# DSSF-Net 3D 交互演示 · P1 装置 + 结果闭环

> 论文：*Animals* 2026, 16, 2796 — 基于 Vis–NIR 透射光谱的鸡胚早期雌雄识别
> 版本：0.4（2026-11-15）｜当前范围：封面式首屏 + P1 深色 3D 展台 + P2/P3/P4 内容页

可运行的项目展示版。首屏是封面式项目介绍，进入后是深色展台上的**装置模型拆解图**：整条透射光路置于全封闭遮光暗箱内（相机在上、种蛋在中、光源在下），3D 以后墙 + 实心左墙 + 落座顶盖（后铰链、前锁扣、密封条）的剖开 / 拆解方式呈现。左侧「全流程」展签列出五步链路并可点击播放讲解，右上角可收回成侧边小标签；光路 / 拆解 / 剖面、300 mm 标尺、采集流程与结果联动，以及 `paper / demo / model` 三档源标识。讲解语音固定为晓晓。

## 1. 运行

当前机器上已有静态服务在跑，直接打开：<http://127.0.0.1:5173/>

一键启动（Windows）：

- `start-demo.cmd`：只起前端静态服务（优先 `node serve.mjs 5173`，端口被占用则直接打开现有服务）。
- `start-all.cmd`：前后端一起起；默认探测 8000，后端未配置时只起前端。参数见 Ops 的 `DEPLOY.md`。
- 手机 / 同网设备：在项目根目录双击 `启动演示-手机.cmd`（即 `node serve.mjs 5180 --lan`），用窗口里打印的 `http://192.168.x.x:5180/` 访问；首次可能需要在 Windows 防火墙允许 Node.js 的专用网络。

手动：

```bash
# 前端（在 dssf-demo/）
node serve.mjs 5173
# 或 python -m http.server 5173 --bind 127.0.0.1

# 后端 mock（在包内 server/，相对 dssf-demo 为 ..\server）
cd ..\server
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

> ES Module + importmap 必须走 HTTP，不能 `file://` 双击。前端默认直连 `http://127.0.0.1:8000`；同源部署走相对路径；`?api=...` 可覆盖。

## 2. 交互

| 操作 | 效果 |
|---|---|
| 拖拽 / 单指滑动 | 旋转；水平约 ±120°，垂直不翻底；阻尼 0.06 |
| 滚轮 / 双指捏合 | 缩放；禁用平移，防丢模型 |
| 点击部件 / 青色热点 | 高亮部件，右侧参数卡显示论文参数 |

| 换一枚蛋 | 生成新的演示样本，重新请求后端 |
| 快捷键 | Space 采集、R 重置视角、E 拆解、B 光路、X 剖面、Esc 关结果 |

### 尺寸对齐（按工业设计图重标）

3D 场景按 **1 世界单位 = 10 mm** 建模：

| 项 | 3D 场景 | 工业设计图 |
|---|---|---|
| 台架 | 120 × 75（1200 × 750 mm 平面） | 1200 × 750 mm |
| 样品平台 | 20 × 20 × 9（200 × 200 × 90 mm） | 200 × 200 × 90 mm |
| 蛋径 | ∅4.5（∅45 mm，40–50 mm 区间） | ∅40–50 mm |
| 镜头–蛋 | 30.0（300 mm） | 300 mm |
| 蛋托 | 三点径向夹爪 | 三点定位结构 |
| 光谱 | 340–1020 nm · 681 点 | 340–1020 nm · 681 点 |

默认演示用低台取景（画面更近、部件更清楚）；加 `?bench=750` 则把台架抬到真实 750 mm 台高（补台架立柱、整体上移、重调相机与阴影范围），两种取景共用同一套几何，没有第二份场景。抬台取景里背景孵化器是落地设备、且未按 1450 mm 实体建模，故**不入画也不参与拾取**，热点由 10 个变 9 个；该视角实测 **19.7k 三角面 / 70 draw calls**（默认视角含孵化器为 20.3k / 72）。光学模块支架（立柱 + 悬臂 + 底座，对照设计图 2）已补进场景，镜头与相机不再悬空。对比图：[工业设计图 vs 3D 场景](shots/08-design-vs-3d.png)，可复现：`node render-right.mjs && python compose-compare.py`；真实台高截图：[bench-750](shots/bench-750.png)、[选中镜头](shots/bench-750-lens.png)。

## 3. 数据来源与口径（重点）

页面的结果卡按 `source` 分三档显示，同屏不混：

| source | 触发 | 结果卡 | 标签 |
|---|---|---|---|
| `demo` | 默认；后端 `demo-surrogate` | 逐蛋概率环 + 固定内测集汇总 | **代理模型 · 非论文权重** |
| `paper` | `?mode=paper` | 不输出逐蛋判定；展示三套论文口径 | **论文值** |
| `model` | 等真实权重接入 | 逐蛋概率 + 模型输出 | **真实模型输出** |
| 离线回退 | 后端不可达（3.5 s 超时） | 本地演示桩，明确提示 | **本地演示桩 · 后端未连接** |

- `demo` 后端只做 ΔS 局部对比的代理评分，**不代表论文精度**；结果卡里的 `note` 会原样显示。
- `paper` 卡同时给出：固定内测集 **91.5%**（n = 200）、跨批次平均 **84.6%**（4 批留一）、AUC **0.966**（95% CI 0.940–0.987）、五折 AUC **0.974**（±0.012）。91.5% 与 84.6% 必须同时出现；0.974 只标 AUC，不叫准确率。
- 页面上的逐蛋曲线是程序化生成的演示曲线（`演示曲线` 标签），不是实测光谱；`paper` 模式也不会把演示曲线包装成论文实测。
- 文字统一写“可见–近红外 / Vis–NIR 340–1020 nm”，不用“红外”。
- Legal 文案已落位：结果卡完整免责声明、页脚“研究演示 · 非生产决策依据”、剖面角标“示意图 · 非真实解剖/医学影像，仅用于说明光路与结构位置”。

### 后端接口

- 目录：`..\server`（相对 `dssf-demo`）
- `GET /health` → `{ ok, version, model: { mode, source, ... } }`
- `POST /api/predict?mode=demo|paper`，入参二选一：
  - `{ "d2": number[681], "d5": number[681] }`
  - `{ "sample_id": "DEMO-0102" }`（或纯数字 `102`）
- 返回：`label / prob_male / prob_female / confidence / source / note`；`paper` 模式下 `label`、`prob_*` 为 `null`，并返回 `paper_reference`（五折 / 固定内测 / 4 批留一三套口径）。
- 前端请求的是 681 点 D2/D5，因此页面显示曲线与后端评分一致；`source`、`note` 直接进结果卡。
- 错误码：`sample_id_or_spectra_required`、`spectra_pair_required`、`spectrum_length`、`bad_sample_id`；前端失败时回退本地演示桩并标注。

## 5. 性能实测

| 指标 | 实测 | 说明 |
|---|---|---|
| 三角面 | **20.3k** | 低于 UIUX 30k 上限；RoundedBox 降段 + 合并平台支撑 |
| draw calls | **72**（选中镜头 76） | UIUX 上限 80 |
| 移动端（390×844，DPR 2） | **18.7k tris / 61 calls** | SwiftShader 软件渲染 |
| 首屏资源 | **862 KB 原始 / 220 KB gzip** | 含 three.module.min + core.min + 3 个 addon + 业务代码 |
| 贴图 | 0 张外部贴图 | 全程序化 Canvas 纹理；未用 `transmission` 材质 |

UIUX 的硬约束按渲染成本执行：draw calls ≤ 80、透明层 ≤ 3、贴图 ≤ 2×2048 + 4×1024、DPR ≤ 2。
